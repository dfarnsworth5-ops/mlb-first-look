🏈 MLB DFS FIRST LOOK

General

DK / FD
DraftKings / FanDuel salary for that game.
Line
Moneyline odds for that team to win the game.
Time (ET)
Scheduled first pitch, Eastern time.
LHP / RHP
Left-handed / right-handed pitcher.
LH / RH / SH
Batter hits left-handed / right-handed / switch-hitter.

Odds & Schedule

A-Total / H-Total
Implied run total for the away/home team, derived from the game total and moneyline.
G-Total
The full game's projected total runs (over/under).

Pitcher Breakdown

OTOT
The opposing team's implied run total. A higher number means a tougher matchup for the pitcher.
xwOBA
Expected weighted on-base average allowed, based on the quality of contact given up rather than actual results.
xERA
Expected ERA based on underlying performance (quality of contact, walks, strikeouts) rather than runs actually allowed.
SIERA
Skill-Interactive ERA — a defense-independent ERA estimator built from strikeout, walk, and ground-ball rates.
ERA
Earned run average.
K%
Percentage of batters faced who struck out.
BB%
Percentage of batters faced who walked.
SS%
Swinging-strike rate — the percentage of pitches that generated a swing and miss.
GB%
Ground-ball rate.
HC%
Hard-contact rate — the percentage of batted balls hit 95+ mph.

Offense Breakdown

Total
The team's implied run total for the game.
TvsLHP / TvsRHP
The team's season-long wOBA against left-handed / right-handed pitching.
PvsLHB / PvsRHB
The opposing starting pitcher's wOBA allowed against left-handed / right-handed batters this season.

Hitter Breakdown

Order
Projected spot in the starting lineup.
wOBA
Weighted on-base average — a single comprehensive rate stat for overall offensive value.
ISO
Isolated power — extra-base hits per at-bat, a pure power measure.
xOBP
Expected on-base percentage, based on quality of contact and plate discipline.
xwOBA / xISO
Expected wOBA / ISO based on quality of contact rather than actual outcomes.
ExitV
Average exit velocity, in mph.
HC%
Hard-contact rate — percentage of batted balls hit 95+ mph.
BAR%
Barrel rate — the percentage of batted balls that are well-struck enough (combining exit velocity and launch angle) to be classified as a "barrel."
BB%
Walk rate.
K%
Strikeout rate.
xwOBAvL / xISOvL / K%vL
The opposing pitcher's expected wOBA allowed, expected ISO allowed, and strikeout rate against left-handed batters.
xwOBAvR / xISOvR / K%vR
Same as above, against right-handed batters.

Color Coding

Every colored stat is ranked against the rest of that day's slate and shaded on a continuous scale — deep blue for the best matchups/performances, deep orange/red for the worst, with lighter shades in between. The scale is calculated automatically from that day's data, so it always reflects the current slate rather than a fixed cutoff.

Data loads from data.json in this same folder. Update that file to refresh the table — no HTML edits needed.
